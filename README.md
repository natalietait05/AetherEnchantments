# AetherEnchantments

A Fabric mod for Minecraft 26.3 that turns utility mechanics into enchantments.

## Included enchantments

- **Lumberjack I–III** — Break a connected tree with an enchanted axe to fell it. Sneak and right-click a tree to strip its connected trunks without breaking them. Higher levels increase the maximum number of processed trunk blocks (8 / 40 / 256).
- **Indestructible** — Prevents supported tools, weapons, and armor from breaking. Enchanted items stop at one remaining durability point, remain usable, and can still be repaired.

The mod also includes the Diminishing Tools item models and textures.

## Requirements

- Minecraft 26.3
- Fabric Loader 0.19.5 or newer
- Fabric API 0.161.0+26.3
- Java 25
